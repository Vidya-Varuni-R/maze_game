# 🧩 Maze Explorer

A simple Tkinter-based maze game where you navigate through a randomly generated maze and race against time to reach the finish point.

---

## 🚀 Features
- Random maze generation  
- Arrow key player movement  
- Timer that tracks completion  
- Option to show the solution path  
- Reset player to starting point  
- Clean and minimal GUI

---

## 📦 Requirements
You need **Python 3.x** installed.

Tkinter usually comes pre-installed.

## 🎮 Controls

| Action | Key |
|--------|-----|
| Move Up | ↑ Arrow |
| Move Down | ↓ Arrow |
| Move Left | ← Arrow |
| Move Right | → Arrow |

Buttons available:
- **🎲 New Maze** – Generate a brand new maze  
- **💡 Show Solution** – Reveal or hide the solution path  
- **🔄 Reset Player** – Return to the start and reset timer
